## 这一页怎么用

- **5 分钟**：读开头的「如果只读 5 句话」和「15 章一句话速览」。
- **想深挖某章**：点速览表里的「▶」，或点下方折叠标题；每章折叠块内先是「本章速览」，再是原文全文。

- 顶部工具条可「展开全部 / 收起全部」，右下角按钮可一键回到导读。
